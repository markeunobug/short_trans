# 水下通信系统硬件方案初步梳理

更新时间：2026-07-15

## 1. 当前结论

这套硬件采用分离的发射板和接收板，但两块板共享同一套数字核心：

- STM32G431RBT3 负责系统管理、两路 RS485、外部 Flash 和与 FPGA 的低速控制通信。
- Intel Cyclone 10 LP `10CL025YE144I7G` FPGA 负责高速波形/采样数据通路。该订货号对应 10CL025、1.2 V 核心、E144 EQFP、工业温度等级、速度等级 7、RoHS 封装；Quartus 工程应直接选择此完整型号。
- FPGA 配有 EPCQ16ASI8N 配置 Flash 和 30 MHz 有源晶振；MCU 使用 25 MHz 有源晶振。
- 发射板把 FPGA 生成的数字波形送入 16 位 DAC，再经精密缓冲和 D 类功放形成差分大功率输出。
- 接收板把换能器/线圈的微弱差分信号经过保护、仪表放大、有源滤波和全差分 ADC 驱动后送入音频 ADC，再以 I2S 送入 FPGA。
- 两块板均带主、备用两路 3.3 V RS485，以及 256 Mbit 外部 SPI NOR Flash。
- 系统为固定的一发一收单工链路；此前使用 2ASK 效果不理想，下一版调制候选为 2FSK 或 Chirp。
- 当前换能器由线圈与外接谐振电容构成，具体线圈参数尚未冻结；目标中心频率约为 1.785 kHz。

因此当前硬件更像一套“MCU 管理 + FPGA 实时基带 + 独立模拟收发链”的水下物理层平台。调制方式、载波频率、符号率、同步、编码和协议尚未由原理图限定，需要在后续方案讨论中确定。

## 2. 发射链路

建议按下面的功能链理解：

`MCU/外部命令 -> FPGA -> DAC8830 -> OPA388 -> TPA3126D2 类 D 功放 -> OUT_P/OUT_N -> 发射换能器`

1. FPGA 通过 `DA_SDI`、`DA_SCLK` 驱动 DAC8830。
2. TXU0102 把 FPGA 侧 1.8 V 逻辑转换到 3.3 V 模拟域逻辑。
3. REF3030 提供 3.0 V 基准，DAC8830 生成 `DA_OUT`。
4. OPA388 以电压跟随方式缓冲为 `AOUT`。
5. `AOUT` 经交流耦合进入 TPA3126D2，功放使用单声道 PBTL 模式，电源为 +20 V。按器件要求，LINP/LINN 在 PBTL 模式下接地，右声道输入 RINP/RINN 接收模拟信号。
6. 功放输出端的多只 3.3 uF 电容属于发射 LC 谐振网络中的电容部分，`OUT_P/OUT_N` 后外接发射线圈；设计意图是通过电容隔直后实现交流并联，而不是直流直接并联功放半桥。
7. 外部 +28 V 经 `SiC461ED-T1-GE3` 同步降压得到 +20 V；原理图标注 `ILIM: 5A`。
8. 功率输出经 J2 引出为 `OUT_P`、`OUT_N`。

## 3. 接收链路

建议按下面的功能链理解：

`COIL_P/COIL_N -> ESD/输入网络 -> AD8429 -> 两级有源滤波 -> ADA4945-1 -> TLV320ADC6120 -> I2S -> FPGA`

1. `COIL_P/COIL_N` 从 CON2 输入，ESD401 对地保护，输入端还配置了并联电容网络。
2. AD8429BRZ 作为低噪声仪表放大器，`RG=62 ohm`。其增益很高，具体增益需结合数据手册公式和实际 62 ohm 精度再次计算确认。
3. U16 为 `OPA2211AIDDAR`，U16.1/U16.2 构成两级有源滤波/增益级，目标中心频率约 1.785 kHz。
4. ADA4945-1 把单端信号变为差分信号，并驱动 `ADCIN_P/ADCIN_M`；`VOCM` 由 REF/VREF 分压后经 OPA388 缓冲产生。
5. TLV320ADC6120 通过 `SDOUT/BCLK/FSYNC` 向 FPGA 输出 I2S/音频串行数据，配置接口为 `AD_SCL/AD_SDA`。
6. 24.576 MHz SiT8924 经 LMK1C1102 分配，一路作为 ADC 的 `I2S_MCLK`，一路作为 FPGA 的 `ACLK_FPGA`。

## 7. 电源树

### 共同数字电源

- +5 V -> EA3059 四路降压 -> `3V3_FPGA`、2.5 V、1.8 V、1.2 V。
- +5 V -> TPS62810-Q1 系列 -> `3V3_MCU`。
- FPGA 各 Bank 按 1.8/2.5/3.3 V 分域，MCU 和外设为 3.3 V。

### 发射板

- +5 V -> TPS7A8300 -> `3V3_A`，供基准、DAC、运放和 3.3 V 逻辑侧。
- +28 V -> SiC46x 系列 U25 -> +20 V，供 TPA3126D2 功放。
- J3 画在 +28 V 与 +20 V 之间，形态类似可选磁珠/跳线。如果 U25 工作，J3 不应无条件短接；必须核实 BOM 的装配属性。

### 接收板

- +5V_A -> TPS7A96 -> `3V3_A`。
- -5V_A -> LT3094 -> -3.3 V。
- 模拟正负电源与数字侧 +5/-5 通过 J1/J3 磁珠或零欧网络隔离。

## 9. 在上电或写代码前必须澄清的问题

1. **发射 LC 参数尚未闭合。** 已确认 C158-C167 为谐振电容、后接发射线圈，但仍需要线圈电感、直流电阻、工作电流下的电感变化，以及电容的实际串并联等效值，才能核算 1.785 kHz 谐振点、Q 值和安全电流。
2. **交流并联 PBTL 需要带负载验证。** 已确认不是 TI 手册中的直接并联，而是有意通过谐振电容隔直后交流并联。需要结合线圈阻抗核算 1.785 kHz 下的电容电抗、四路输出电流分配、器件间直流偏差和单路过流风险。
3. **UART 是否启用 TX/RX swap。** PA2/PA3 与 PC4/PC5 的收发器方向对应 USART 复用功能的交换布局，需要确认这是有意设计，并在固件中设置 `USART_CR2.SWAP`。
4. **调制参数尚未冻结。** 已确定单工并优先考虑 2FSK，但目标净速率、传输距离和 2FSK 频偏仍待确定。
5. **部分阻容值为空。** 发射功放周边的 R121/R122/R124/R125/C168/C169，以及 U25 周边 R133/R134 等缺值，会影响模式、输出网络和电源设计。
6. **连接器应以 PCB 网络表为最终依据。** PDF 中 J2/CON2 的并联针脚较密，线束制作前需要 EDA 源文件或网表复核。

## 10. 后续讨论建议顺序

1. 测量线圈电感、直流电阻、谐振带宽和最大安全电流，闭合 1.785 kHz LC 参数。
2. 复核并锁定 TPA3126D2 PBTL 输出网络以及 +28 V/+20 V 电源设计。
3. 根据实测接收信号确定最大/最小输入和动态范围，核算 AD8429、OPA2211 与 ADC 全链路增益。
4. 在 2FSK 与 Chirp 之间完成台架对比，随后冻结同步、帧结构和纠错方案。
5. SPI1 作为主用通道，定义 STM32 主机读取 FPGA 接收帧的速率和寄存器/FIFO 协议；SPI3 暂不初始化，保留备用。

## 11. 当前接收滤波器 Q 值估算

按原理图现有值，并把 OPA2211 视为理想运放：

- 第一级：R74=3.3 kohm、R75=5.6 kohm、C117=10 nF、R76=33 kohm、C118=10 nF，幅频峰值约 1.923 kHz。
- 第二级：R77=4.7 kohm、R78=4.7 kohm、C119=10 nF、R79=36 kohm、C120=10 nF，幅频峰值约 1.730 kHz。
- 两级级联合成峰值约 1.822 kHz；1.785 kHz 相对峰值衰减不足 0.001 dB。
- 两级级联的约 -3 dB 频带为 0.601–5.526 kHz，带宽约 4.925 kHz，按 `Q=f_peak/BW` 得 `Q≈0.37`。

这个 Q 表示接收有源滤波器本身是宽带的，并不会限制在 1.785 kHz 附近布置两个 FSK 频点。系统最终 Q 仍由外部线圈、谐振电容、线圈电阻、水下机械/声学负载及 ADA4945 后级共同决定，应以整机扫频得到的 -3 dB 带宽计算。
