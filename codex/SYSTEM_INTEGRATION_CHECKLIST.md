# 水下短距离通信系统联调清单

更新时间：2026-09-03  
适用范围：`short_trans` V1.0，1.6/2.0 kHz、100 bit/s 非相干 2FSK

## 1. 联调目标与边界

本工程需要区分两个验收目标：

1. **V1.0 接收链路联调**：使用 STM32 PA4 DAC 或信号源产生测试 2FSK，验证接收板从模拟输入、ADC、FPGA 解调到 STM32/RS485 输出的完整链路。
2. **真实收发整机联调**：使用发射板外部 DAC8830、TPA3126D2、发射换能器和水下信道，将数据送到接收板并恢复 Payload。

当前可以立即开展目标 1。目标 2 还需要实现 FPGA 到 DAC8830 的发射驱动，并完成发射功率级、线圈和谐振网络验证。

## 5. 分阶段联调清单

### 阶段 A：RS485 与 MCU 独立验证

- [ ] 只连接 PC 与 TX 板 RS485A，发送 `HELP`、`STATUS`，确认有稳定回复。
- [ ] 只连接 PC 与 RX 板 RS485A，发送 `PING`、`HELP`、`STATUS`，确认有稳定回复。
- [ ] 确认 USART1 为 115200-8-N-1，PC4/PC5 swap 生效。
- [ ] 示波器检查 PA7：空闲低，发送期间高，最后停止位发送完后回到低。
- [ ] 检查 A/B 差分波形、极性和终端电阻；重复 100 次命令，无超时和乱码。
- [ ] 确认 `STATUS` 中 `uart_err=0`、`overflow=0`。

通过标准：两块板各自能稳定完成 PC -> 板 -> PC 的双向 RS485 通信。

### 阶段 B：RX 板数字接口与 ADC 启动

- [ ] 重新编译并下载最新 `rx_cyclone10.sof`。
- [ ] 烧录最新 RX STM32 固件。
- [ ] SPI 读取 `DEVICE_ID=0xA7`、`FW_VERSION=0x10`。
- [ ] 验证 SPI1 Mode 0、SCK 约 1.172 MHz、NSS 和 MISO 高阻状态。
- [ ] 确认 ADC I2C 地址 `0x4E`，初始化完成且无锁存错误。
- [ ] 读取关键 ADC 寄存器，确认回读与固定 ROM 一致。
- [ ] 测量 MCLK 24.576 MHz、BCLK 3.072 MHz、FSYNC 48 kHz。
- [ ] 连续复位和重新初始化至少 10 次，确认启动结果一致。

通过标准：STM32 能稳定识别 FPGA，ADC 初始化和三个关键时钟均正确。

### 阶段 C：真实 ADC 采样

- [ ] 先用低幅度、带直流隔离的 1.6 kHz 正弦输入 RX 模拟前端。
- [ ] 触发并完整读取 1024 点快照，保存原始数据文件。
- [ ] 核对 I2S 字节序、符号位、CH1 通道和 `SAMPLE_SHIFT`。
- [ ] 检查快照最大值、最小值、直流偏置和削顶计数。
- [ ] 对 2.0 kHz 重复快照和频率识别。
- [ ] 扫描输入幅度，确定无削顶工作范围及最小可识别幅度。
- [ ] 输入静默/短路基准，记录噪声底和自适应门限稳定时间。

通过标准：两种单音都能从真实 ADC 快照中正确识别，无位错、通道错或异常削顶。

### 阶段 D：PA4 台架 2FSK 到 RX 的闭环

- [ ] 确认 PA4 与 RX 输入之间的安全耦合、衰减和共地方案。
- [ ] 示波器确认 PA4 DAC 更新率为 48.000 kSPS。
- [ ] 验证 `TONE1600` 和 `TONE2000` 的频率、幅度和直流中点。
- [ ] 验证 `ALT` 每 10 ms 切换频点且无异常中点跳变。
- [ ] 从低 `AMP` 开始逐步增加，确认 RX ADC 不削顶。
- [ ] 发送 0、4、16、32、64 byte Payload，逐字节比较 RX `READ` 结果。
- [ ] 注入 CRC 错误或错误同步字，确认错误帧不进入正常 FIFO。
- [ ] 连续发送多帧并延迟 STM32 读取，验证帧顺序、POP/DROP 和溢出行为。
- [ ] 重复至少 100 帧，记录成功帧数、CRC 错误、失锁和超时。

通过标准：PA4 产生的真实模拟 2FSK 经 RX 模拟前端、ADC、FPGA 和 STM32 后恢复出一致 Payload。

### 阶段 E：性能与门限标定

- [ ] 扫描 `SAMPLE_SHIFT`、能量倍率、噪声偏置和置信度门限。
- [ ] 扫描载波频偏 0、±5、±10、±20 Hz。
- [ ] 扫描输入幅度和 SNR，记录 BER/FER 曲线，不预设未经实测的最低 SNR。
- [ ] 测量 1.6 kHz 与 2.0 kHz 在整条 RX 模拟链上的增益差。
- [ ] 测试随机起始相位、帧间静默、连续帧和重新捕获时间。
- [ ] 将最终参数、环境、线缆、增益档位和仪器设置写入测试记录。

通过标准：门限来自实测数据，并能在目标幅度、频偏和噪声范围内稳定复现。

### 阶段 F：真实发射板与功率级

- [ ] 实现并仿真 FPGA 到 DAC8830 的串行驱动和 48 kSPS 波形输出。
- [ ] 在不启用功放时验证 DAC8830 数字时序、参考电压、输出码和 OPA388 缓冲输出。
- [ ] 低电压、限流、假负载下验证 TPA3126D2 PBTL 模式和输出波形。
- [ ] 核实 U25 的 28 V -> 20 V 电源、J3 装配属性和功放周边缺失阻容值。
- [ ] 接入线圈前完成 LC 谐振、电流分配、器件温升和过流裕量核算。
- [ ] 接换能器后从低电压和短脉冲开始，记录电流、波形、谐振频率和温升。

通过标准：真实发射板电气链路可控、无过流或异常温升，并能被 RX 板稳定解调。

### 阶段 G：水下整机验收

- [ ] 固定收发换能器方向、深度、间距和水池环境，形成可重复夹具。

- [ ] 验证断电重启、丢载波、失锁后重新捕获和异常帧恢复。
